MORROW ORACLE XE 11G NOTES

This project version targets the XE service/SID seen in the user's listener output: XE on port 1521.

1. Edit database/00_create_app_user.sql and replace its example password.
2. Connect as Oracle administrator with `sqlplus system@XE`, then run `@database/00_create_app_user.sql`.
3. Connect with `sqlplus MORROW_APP@XE`, then run `@database/01_schema.sql`.
4. If you previously attempted to run the older Phase 3 schema, check for partial MW_ tables/sequences/triggers first. If any exist, do not blindly rerun 01_schema.sql; remove the partial objects deliberately or use a clean schema.
5. This is a legacy compatibility variant. The `ojdbc8` 12.2 driver line is not certified for Java 21, even though it may work; full runtime compatibility must be confirmed on the user's machine.
